# Noto Sans KR

Source: [Google Fonts Noto Sans KR](https://github.com/google/fonts/tree/main/ofl/notosanskr), variable `NotoSansKR[wght].ttf`.

`NotoSansKR.woff2` is a local web subset for Latin, Hangul/Jamo, Korean punctuation and full-width characters. FontTools created the WOFF2 subset without changing outlines. The remaining glyphs use the system fallback. `OFL.txt` contains the upstream SIL Open Font License 1.1.

The font is served locally; no Google Fonts request is made by the application. FontTools and Brotli were asset preparation tools only and are not application dependencies.
